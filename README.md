# 瑀光官方網站

網站網址：https://ian94134.github.io/yuguang-official-website/

## GitHub Pages 部署

網站由 `main` 分支的根目錄發布，無需建置。更新 `index.html`、`styles.css` 或 `script.js` 並提交後，GitHub Pages 會自動重新發布。`.nojekyll` 讓 GitHub 直接提供靜態檔案。

這是一個以純 HTML、CSS 和 JavaScript 製作的響應式網站原型。可直接以瀏覽器開啟 `index.html` 預覽，不需要安裝套件。首頁課程卡的「查看課程資訊」會在同一頁切換到課程詳情；資訊頁含簡章摘要、90 分鐘體驗流程、報名按鈕與相關課程推薦。

## 上線前需要補齊

- **課程資料：**五堂課資訊依 Drive 課程簡章摘要製作。簡章未載明的場次、地點及費用在網站標示為洽詢／另行公告，正式招生前請補上；相關課程與流程位於 `script.js` 的 `courses` 物件。
- **社群網址：**頁尾 Facebook、Instagram、LINE 目前連到各平台首頁；替換成瑀光的官方帳號網址。
- **會員系統：**現在報名表是前端介面預覽，不會建立帳號、儲存或傳送個資。上線需有後端處理訪客／上課學員／精油會員註冊、登入、會員資料、課程名額與報名紀錄。密碼必須只在後端安全雜湊，不能存於瀏覽器。
- **金流：**表單已提供綠界科技與 LINE Pay 選項；正式付款需有商家帳號、後端訂單建立與付款結果通知。API 金鑰等憑證只放在伺服器環境變數，不能放進前端程式碼。
- **隱私與交易規則：**上線前補上隱私權政策、服務條款、取消／退費規則與客服聯絡方式，並將同意文字連到相應頁面。

## 修改課程與品牌

- 課程卡片與報名表選項位於 `index.html`。
- 品牌色、字體、版面與行動版樣式位於 `styles.css`。
- 導覽、課程篩選與預覽表單行為位於 `script.js`。
