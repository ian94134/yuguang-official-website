# 瑀光官方網站

這是一個以純 HTML、CSS 和 JavaScript 製作的響應式網站原型。請將網站完整資料夾解壓後，以瀏覽器開啟 `index.html`；不要只複製 HTML、CSS 與 JavaScript，照片素材需保留在 `assets/course-photos/`。首頁課程卡的「查看課程資訊」會在同一頁切換到課程詳情；已有資料的課程保留原簡章摘要，其他主題標示依正式簡章公告。

## 上線前需要補齊

- **課程資料：**網站依提供的課程清單整理為 24 個不重複主題。清單未載明的課程內容、適合對象、場次、地點與費用在網站標示為依正式簡章公告或洽詢；課程資料位於 `script.js` 的 `courseCatalog`。
- **社群網址：**頁尾 Facebook、Instagram、LINE 目前連到各平台首頁；替換成瑀光的官方帳號網址。
- **會員系統：**現在報名表是前端介面預覽，不會建立帳號、儲存或傳送個資。上線需有後端處理訪客／上課學員／精油會員註冊、登入、會員資料、課程名額與報名紀錄。密碼必須只在後端安全雜湊，不能存於瀏覽器。
- **金流：**表單已提供綠界科技與 LINE Pay 選項；正式付款需有商家帳號、後端訂單建立與付款結果通知。API 金鑰等憑證只放在伺服器環境變數，不能放進前端程式碼。
- **隱私與交易規則：**上線前補上隱私權政策、服務條款、取消／退費規則與客服聯絡方式，並將同意文字連到相應頁面。

## 修改課程與品牌

- 課程卡片、報名表選項與課程資料位於 `script.js`；頁面架構與 FAQ 位於 `index.html`。
- 品牌色、字體、版面與行動版樣式位於 `styles.css`。
- 導覽、課程篩選與預覽表單行為位於 `script.js`。
- 寫實照片位於 `assets/course-photos/`，依主題選圖並經暖柔色調與裁切處理；首頁、課程卡與詳情頁皆使用同一組素材。分享 ZIP 需包含 `assets/` 資料夾，否則相對路徑會找不到圖片。
